# 女巫塔前：敌人与友方 NPC

本图已进入正式选关，地图事件与五项任务已接入。总轮数暂沿用16轮。珞珞、小白各掉落12金币，赤痕、变彩各掉落16金币，晕彩掉落仍为0。玩家、友方NPC（普攻或技能）和召唤物击倒怪物时，掉落金币均计入玩家，任务进度照常累计；NPC和召唤物击倒不触发玩家专属击倒词条。金币奖励与赤痕调整后已完成新图3,200局固定策略复测，记录见工作区 analysis/tower-rebalance-2026-10-03-summary.json；历史零掉落版记录保留。

## 数据与登场

`js/data.js` 的 `monsters` 注册珞珞、小白、赤痕、精英变彩、魔法少女·晕彩；`npcs` 独立注册桃夭、曼珠沙华、铃兰、白水仙。实验室的 BOSS 变彩保持原定义，游荡魔物、雷鸟、三头犬复用原定义。

地图 `enemyRoster`、`npcRoster` 记录阵容，不自动投放。正式安排可通过 `initialNpcs: [{ npc: "npc_taoyao", tile: 16 }]` 配置初始友方，通过 `globalEvents[].npcSpawns` 使用同样结构配置增援；敌人沿用 `globalEvents[].spawns`。条目可带 `dir` 指定登场首步方向。配置校验覆盖 NPC 引用、落点范围和方向向量。

02、04、29、30 为游荡魔物刷怪格，玩家停留时各生成一只；开局不在刷怪格铺怪，随机地块事件排除刷怪结果。第一轮事件显式允许在三个回血格各投放一只游荡魔物，其余事件默认禁止投放小怪。精英变彩的卡牌释放是独立技能，可在随机两个不同地块各生成一只游荡魔物。

## 地图事件与任务

- 第1轮「双方对峙」：桃夭、曼珠沙华、铃兰、白水仙依次在02、04、08、10格登场，首步向下；珞珞、小白分别在22、24格登场，首步向上；变彩在33格登场，方向随机；12、25、26三个回血格各生成一只游荡魔物。
- 第3轮「红色风暴」：赤痕在23格登场，首步向上；所有敌人攻防+1。
- 第11轮「魔力强化」：所有敌人攻防+1。
- 特殊事件「晕彩降临！」：赤痕被击倒时只累计任务进度；轮末任务结算发放三级筹码奖励，并将事件加入待触发队列；下一回合开始时，晕彩在23格向上登场，全体敌人攻防+1。不会在击倒瞬间或任务结算当下登场。该事件每局仅一次，重开清空队列。

回合开始先处理当轮日程事件，再处理已排队的特殊事件；两者如同轮发生，强化分别累加一次。全局强化包含BOSS，也适用于此后刷出的敌人；轮次回退不会重复结算。选筹码挂起不改变事件的回合开始时点。

任务依次为：击倒游荡魔物4只奖励一级筹码；击倒珞珞或小白累计2只奖励二级筹码；击倒赤痕奖励三级筹码并安排特殊事件；击倒变彩奖励三级筹码；晕彩生命降至最大生命的一半及以下完成胜利任务。击倒任务奖励沿用轮末三选一队列，NPC和召唤物击杀也计数，融合不计击倒。

半血任务由实际伤害记录进度，统一在轮末任务结算时复核并判定胜利，覆盖玩家战斗、效果牌、范围波及、青焰、NPC和召唤物。达到半血不会提前停止本轮反击、移动或后续单位行动；结算时仍在场的晕彩必须处于最大生命50%及以下，如果期间回复至半血以上则不能胜利。若已被击倒并移除，则保留达成进度，在轮末获胜。最后一轮也先结算胜利任务，再判定轮数耗尽。无需击杀晕彩，也不必先完成其他任务。其他地图仍以击杀BOSS获胜。

## 行动与战斗

顺序为玩家 → 玩家召唤物 → 友方 NPC → 敌人。NPC 有独立状态列表、生命与技能冷却；每阶段以开始时的 NPC 名单依次行动，死亡单位退出名单，重开会取消旧阶段续接。

按已确认规则，新敌人均主动攻击且会反击，基础移动 1d10。NPC 基础移动 1d10，沿道路追击可主动攻击的敌人，进入敌人格时攻击格上可攻击的敌人；普通攻击采用双方 d6 攻防结算。击败奖励和任务计入玩家，不触发玩家专属命中、击杀技能或筹码。NPC 死亡退场，当前没有复活机制。

珞珞不能被玩家普通交战、突击、效果牌锁定、NPC 或使魔普攻选中，也不受青焰等地块效果伤害。光学隐身不等于全来源免伤：定向爆破的范围波及仍可命中，桃夭的映霞可命中且优先选择珞珞。

白水仙不会被敌人主动攻击，也不受自己主动攻击引发的反击；范围技能与缠绕仍可伤害她。曼珠沙华按结算伤害回复生命，上限为最大生命，结算在敌人反击之前。

## 缠绕与光环

赤痕裁光（劣化）CD3，给所有存活友方单位（玩家、NPC、召唤物）各加2层缠绕，倒地玩家不受影响。晕彩裁光不在登场或普通行动开始时施放。轮末半血胜利任务结算时，先发动一次裁光，给所有在场友方NPC增加999层缠绕，然后立刻触发一次缠绕效果（按当前层数结算减速和伤害，无需等待下回合），击倒NPC（包括白水仙）并令其退场，再结算本关胜利。玩家与召唤物不受影响；提前已退场的NPC不会重复处理。单次爆发直接击倒晕彩时，也会保留目标记录以完成终场流程。

玩家、NPC和召唤物各自在自己回合开始按缠绕层数受到伤害，并记录同等本回合移速减值；移动步数最低0。缠绕不会自然递减。玩家、NPC、召唤物之间实际移动经过彼此时，移动方与每名同格存活友方各减1层（最低0）。使魔自身没有缠绕也能帮助友方解缠；起步同格、同格召唤不算经过，死亡或倒地单位不参与。赤痕的缠绕覆盖召唤物；晕彩终场裁光仍仅作用于友方NPC。已锁定的本回合减速不因途中解缠而返还步数。玩家伤害沿用受伤、筹码和凤凰再生规则，NPC或召唤物因缠绕致死则立即退场，不再施法或移动。

铃兰存活在场时，全体友方（包括铃兰自己和召唤物）移速+2，退场即取消光环；缠绕减速与之叠加。遥控骰子的固定移动也计入这两项修正，其余旧有固定骰规则保持一致。

红外领域仅在噩梦、疯狂难度下，在赤痕每次行动开始触发，以道路距离计算3格范围，造成3点伤害，覆盖玩家、NPC、召唤物。主动技能处于冷却时领域仍生效。

## 强化、融合与减伤

魔物重塑只在精英变彩自己移动经过游荡魔物时触发，每次攻击+1、最大生命+2，不额外回复当前生命。分别记录每只素材的累计强化；两只魔物融合成雷鸟或三头犬时继承双方强化之和，融合产物满血且当轮不行动。不继承素材的基础数值，也不重复计算全局强化。

晕彩折光在标记增伤之后减伤2，覆盖战斗、效果牌、范围波及、青焰、NPC和召唤物伤害；沿用当前游戏的命中伤害最低1规则。

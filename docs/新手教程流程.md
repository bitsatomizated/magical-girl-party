# 新手教程：11 节操作流程

## 入口与原则

开始页「新手教程」与「玩法介绍」并排。正式选关只展示女仆咖啡厅、卡牌实验室；练习环道从列表隐藏，底层数据继续用于教学与规则测试。

本版面向桌面浏览器，不包含手机适配。固定使用像素喵喵，每节独立重置场景，可重试、退出。阅读不计时、不推进轮次；操作练习必须实际完成。切换教学关注区域时高亮并自动定位，普通重绘不抢夺滚动位置。

前十节固定关键移动距离、双方战斗骰点（3）和战斗牌随机值（取范围内的 2）；毕业战恢复随机战斗。技能、伤害、移动方向、事件、任务、购物、升星和筹码均使用正式引擎。界面明确标注教学演示与正式随机规则的区别。

## 1. 先认识游戏界面

点击「看下一处」逐项观察，支持「上一处」回看；导览中不能推进对局。

1. **获胜目标与顶部状态栏**：限定轮数内击败地图 BOSS 才获胜；认识生命、星级、金币、攻防、技能冷却、阶段和轮次。
2. **棋盘与地图情报**：认识位置、方向箭头，查看真实显示的事件日程、任务进度、奖励和图例。
3. **手牌与操作区**：区分效果牌和战斗牌，找到技能、结束出牌、移动按钮，理解按钮禁用的常见原因。
4. **我的技能与筹码**：阅读主动、被动和坚固 I；筹码名称支持悬浮查看说明。
5. **怪物图鉴与个体状态**：图鉴解释品种技能和行为；棋盘显示每只怪物当前生命、标记与剩余 CD。
6. **日志**：回看伤害计算、技能、抽牌和金币变化。点击「完成导览」后进入操作练习。

## 2. 移动与拿牌

空手牌、无敌人。结束出牌 → 固定移动 1 格 → 停在拿牌格真实抽 2 张牌 → 第 2 轮开始时完成。

说明每轮顺序、普通移动不能掉头，以及停在拿牌格抽 2 张的规则。

## 3. 岔路与方向抉择

使用六格环道加中间捷径：起点 0 → 岔路 1；右方 2 为掉血格，下方 4 为回血格。

1. 第一轮结束出牌、固定移动 2 格，到岔路暂停。起点作为来路不可选。
2. 观察地块，点击下方高亮回血格 4。本轮限定练习安全路线。
3. 第二轮点击「方向抉择」，再结束出牌、移动。
4. 首步出现多个候选，包含来路；点击上方岔路格 1，实际掉头。
5. 第二步恢复禁止掉头，刚才的回血格 4 不再可选；选择左方起点 0。
6. 第 3 轮开始且回到起点时完成。

强调：岔路选择不需要卡牌；方向抉择只改变下次移动的首步，不允许整段移动任意掉头。

## 4. 效果牌与攻击

手牌为板砖、攻击中；两格外有 8 HP、0 防御的驻守假人。

板砖 → 点击敌人编号或图鉴条目 → 假人剩 3 HP → 结束出牌 → 移动 2 格 → 交战 → 攻击中 → 结算攻击。

攻击中花费 1 点、示范增加 2 攻击；双方骰点固定 3，近战伤害为 `(3 + 2) + 3 - (0 + 3) = 5`，击倒假人获得金币。第 2 轮开始时完成。允许取消瞄准重选，不消耗牌。

## 5. 防御与闪避

下一格有 20 HP、攻击 5、0 防御的驻守反击假人；手牌为防御中。

移动交战 → 结算攻击 → 假人存活并立即反击 → 防御中 → 选择防御或闪避。

防御牌增加 2 防御，防御受到 2 点伤害；本节双方骰点相等，闪避成功。两种选择均可完成。说明正式骰点随机，防御牌不帮助闪避，闪避失败按 0 防御结算，攻击和防守分别计算战斗点数。

## 6. 主动技能

发动像素化，观察攻击从 3 变为 7、技能进入冷却 → 结束出牌 → 移动 1 格 → 巡逻假人经过却不能主动攻击 → 第 2 轮开始。

说明效果持续到下回合开始，冷却减少 1；免主动攻击不等于免反击。

## 7. 观察敌人，再决定交战

同时展示训练假人（小怪）、警戒守卫（精英）、灾厄核心观察样本（BOSS）；玩家只有 8 生命。

1. 阅读类型标签：小怪通常提供金币和任务进度，精英需要重点观察特殊技能，BOSS 是获胜目标。类型不能代替具体数值与技能判断。
2. 回答「击倒哪种敌人直接获胜」；正确选项为本地图 BOSS。答错解释原因，不推进。
3. 阅读警戒守卫：驻守、不主动攻击，但会反击；主动「重击准备」就绪时攻击骰点 +2，冷却周期 CD3；被动「汲取」在造成伤害后恢复等量生命。
4. 对照棋盘 CD1，理解当前剩余冷却与技能周期不同；怪物行动时先递减，再按技能触发时机生效。
5. 判断当前是否适合近战；正确选择「会反击并汲取生命，现在先避开」。答错保留信息并允许重选。
6. 结束出牌 → 移动到守卫处 → 真实交战询问中点击「避开」。
7. 下一轮开始完成：没有受到反击，停在回血格按真实规则回复 2 点生命，敌人仍存活，守卫 CD 已变为 0，没有通关。

说明主动技能、被动与反击标签分别代表不同信息；避开一次近战不代表免疫远程技能等其他伤害。

## 8. 商店与金币

18 金币、空手牌 → 移动 1 格到商店 → 停留随机获得 1 张牌 → 勾选固定出售的蛋糕 → 支付 3 金币购买 → 离开商店。

下一轮完成，说明购买顺序、金币限制和 8 张手牌上限。

## 9. 升星与筹码

0 星、15 金币 → 移动到升级点 → 自动支付 15 金币升到 1 星 → 攻击 +2、移速 +1、战斗点数上限为 4 → 从锋利 I、坚固 I、学识 I 中任选一枚。

下一轮完成，说明筹码为局内被动效果，学识在回合开始抽牌。

## 10. 地图事件、任务与奖励

事件栏和任务栏持续可见。开始时没有敌人，任务进度为 0/1。

1. 阅读日程：第 2 轮「训练增援」，前方出现训练假人。
2. 第一轮结束出牌、移动 1 格；第二轮开始时引擎真实触发事件、刷出假人，日程标为本轮触发。
3. 第二轮移动 1 格交战；打出暗影突袭（花费 2 点、攻击 +3），结算 6 点伤害击倒假人。
4. 观察实时进度变成 1/1。轮末判定任务完成，弹出筹码奖励。
5. 任选一枚，奖励队列排空后进入下一轮，本节才完成。

强调地图事件在指定轮次开始触发，任务是玩家完成条件后的奖励机制；完成任务、刷够金币、击倒精英都不代替击败 BOSS 的通关条件。

## 11. 毕业战

使用带岔路的六格地图。右方掉血格 2 驻守精英守卫，右下格 3 是 10 HP、攻击 2、0 防御、会反击的训练版核心。角色 1 星、持有锋利 I，手牌为板砖、暗影突袭、防御中、蛋糕。

1. 阅读精英技能与位置，回答路线判断题：建议经下方回血格绕开守卫接近核心。
2. 自行组合技能、效果牌，建议像素化并用板砖攻击核心（注意选择正确目标）。
3. 固定移动距离 3 格，但必须亲自选岔路；建议路线 0 → 1 → 4 → 3。其他合法路线仍可选择，并承担相应遭遇。
4. 根据遇到的是精英还是核心，自由选择交战或避开；核心战建议暗影突袭后结算攻击。
5. 战斗骰点与牌面数值恢复随机，只有引擎确认核心被击败才毕业。失败可重试本节。
6. 可返回开始页，或以像素喵喵、普通难度进入女仆咖啡厅的原有地图介绍流程。

## 实现与验证

- `js/tutorial.js` 使用稳定章节 ID，负责场景副本、步骤、阅读与判断题、权限和提示。
- `UI.renderAll()` 渲染前更新步骤，渲染后高亮。选向调用真实 `Engine.pickMoveStep()`；事件、任务和奖励使用原引擎流程。
- 引擎公开入口再次校验教学权限，直接调用也不能跳过必做步骤。`leaveGame()` 停止旧局，防止退出、重试后的异步结算污染新局。
- 教学不改写正式内容注册表、不增加 `maidparty_wins`。新版完整毕业记录为 `maidparty_tutorial_v2=complete`；旧版完成不冒充已学完新增内容。
- 无法使用本地存储时仍可完整游玩；不保存中途章节进度。

`npm test -- tutorial-test.js` 验证全部 11 节 DOM 操作、两种防守、三种筹码、错误判断、普通与特殊掉头、真实事件任务奖励、退出重试、旧异步隔离和正式局恢复。`npm test` 与 `npm run validate:config` 验证整体回归。

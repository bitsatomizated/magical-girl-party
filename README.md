# 魔法少女派对

回合制棋盘探索 + 卡牌战斗的网页游戏。纯静态实现，不需要构建步骤，浏览器打开即玩。

**在线试玩：** https://bitsatomizated.github.io/magical-girl-party/

## 玩法概要

- **目标**：在限定轮数内找到并击败隐藏在地图中的最终 BOSS。
- **每轮流程**：出牌阶段使用效果牌 → 掷骰沿道路移动 → 途经地块触发效果（商店 / 拿牌 / 回血掉血 / 刷怪）→ 怪物依次行动。
- **移动**：普通移动不能掉头；“方向抉择”允许下次移动的首步选择任意相邻格（含来路），后续仍不能掉头。岔路口点击高亮地块选择方向。途经怪物时先询问是否交战，结算完毕后再触发地块效果。
- **战斗**：战斗点数为「3 + 星级」，可打战斗牌加攻 / 加防，随后双方各掷一颗骰子比大小，伤害保底 1 点。被攻击时选择防御或闪避；会反击的怪物被攻击后立刻还手。
- **卡牌与筹码**：基础手牌上限 8 张，持有「扩容」后为 10 张；战斗牌只能在战斗中使用，效果牌只能在出牌阶段使用。筹码是局内被动遗物，通过任务、升星、筹码商店三选一获得。新增「增幅」「引导」「扩容」「循环」的规则见 [筹码补充规则](docs/筹码补充规则.md)。
- **金币 / 星级 / 任务**：击败怪物与事件获得金币，在升级点消费金币升星，提升属性并解锁更好的筹码概率；完成地图任务可额外获得筹码三选一。

## 运行

开始页的「新手教程」提供 11 节桌面端教学：界面导览、移动、岔路与方向抉择、效果牌与攻击、防御与闪避、主动技能、敌人类型与技能判断、商店、升星与筹码、地图事件与任务、毕业战。每节可重试或退出，毕业后可直接进入女仆咖啡厅；教学不计入正式胜场。练习环道保留为教学与测试数据，不再展示于正式选关。具体流程见 [新手教程流程](docs/新手教程流程.md)。

站点是纯静态文件，用任意静态服务器托管本目录即可：

```
python -m http.server 8642
```

然后打开 http://127.0.0.1:8642/ 。也可以直接双击 `index.html`，但部分浏览器对本地文件的脚本与图片加载有限制，推荐使用本地服务器。

需要支持 WebP 的现代浏览器（Chrome / Edge / Firefox / Safari 14+）。

## 开发与测试

游戏运行仍然不需要 Node.js 或构建工具。开发测试使用 Node.js（本地验证版本为 24），在本目录执行：

```sh
npm ci
npm run validate:config
npm test
```

`npm test` 自动发现 `test/` 下的 `.js` 测试，在独立进程中依次执行，失败或超时返回非零退出码。默认只检查本地文件，不访问线上站点。单个脚本和线上部署可分别检查：

```sh
npm test -- ask-panel-test.js
npm run test:live
```

浏览器按 `index.html` 的顺序加载子系统和引擎；Node 测试可以直接加载 `js/engine.js`。DOM 测试与工作区的平衡模拟通过 `tools/runtime-source.cjs` 读取页面脚本清单，新增模块时无需维护额外清单。测试需要内部规则时使用显式的 `Engine._test` 接口，不修改源码字符串注入导出。

子系统通过 `create(...)` 接收状态访问函数、随机数或渲染回调，不直接操作 DOM。界面按钮与引擎入口共用 `Engine.canAct(...)`；询问按队列逐个回答，等待回答期间仍可浏览手牌和怪物信息。回合调度由 `turns.js` 负责，战斗、移动和地块的具体规则仍在引擎中。

调度顺序为：轮次事件与复活 → 等待轮末奖励选完 → 玩家回合开始 → 玩家行动 → 回合结束效果 → 友方召唤物 → 怪物 → 任务与轮数判定。怪物名单在行动过程中动态读取，让新分身当轮行动；融合产物仍跳过当轮。`S.phase` 供界面判断操作阶段，调度器内部阶段负责一次性续接；`S.aiBusy` 从 AI 排队起覆盖友方和敌方阶段。技能和持续效果不会因重复收尾而重复结算。

扩展异步流程时，定时任务交给调度器，跨 `await` 续接前检查 `turns.checkpoint()`，移动完成交给 `completeMove`；不要另开一条 AI 回调链。重开在配置校验成功后取消旧定时任务，终局也会停止调度。已唤醒的旧 Promise 由对局检查点阻止继续结算。`turn-scheduling-test.js` 使用可控时钟检查顺序、重复回调、奖励挂起及等待期间重开。

新增角色与怪物的参数、技能注册示例及完整时机表见 [内容扩展与技能时机](docs/内容扩展与技能时机.md)。角色成长由 `starGrowth` 配置，召唤类型和成长按单位类型独立管理，技能通过 `effect` 查找独立处理器。时机文档可用 `npm run docs:effects` 重新生成，或用 `npm run docs:effects -- --check` 检查同步。

页面加载和每次新局开始前都会校验整个内容库，包括隐藏地图。错误会报告具体路径，例如 `maps.card_lab.globalEvents[0].spawns[0].mob`；校验失败不会重置旧对局。`npm run validate:config` 提供独立命令行检查，失败返回非零退出码。新技能通过 `registerEffect(effect, hooks, parameters)` 同时声明参数规则，规则与处理器放在一起维护；完整语法和校验边界见扩展文档。

## 素材说明

运行规则与数值以 `js/data.js` 为准。外层 `data/samples/*.json` 是设计样例，不参与游戏加载；样例中的角色技能描述应与运行数据保持一致。

角色立绘为 AI 生成图像，其中包含已获授权的第三方原创角色（OC）形象。

## 仓库说明

本仓库同时保存游戏源码、本地测试和锁定的依赖清单；`node_modules/` 不纳入版本管理。站点仍可直接作为静态文件发布。完整设计文档、原始素材和平衡分析保存在外层工作区，不在此仓库内。
